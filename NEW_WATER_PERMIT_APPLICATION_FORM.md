## FORM STRUCTURE SUMMARY

### Required Sections:
1. **Identification and Address of the Applicant** (7 fields)
2. **Source of Water** (5 main fields with sub-options)
3. **Intended Activity** (Activity selection + Water abstraction table + Concession details)
4. **Ownership of Adjoining Land** (2 questions with conditional file upload)
5. **Payment Information** (Proof of payment upload)
6. **Annexes** (Activity-specific additional requirements)

### Field Types Used:
- Text inputs
- Email inputs
- Select/Radio buttons
- Checkboxes (multiple selection)
- Number inputs
- Date/Duration inputs
- File uploads
- Address components (Province, District, Sector, Cell, Village)
- Coordinate inputs
- Table/Grid inputs (for water abstraction quantities)

### Key Features:
- Multi-section form structure
- Conditional fields based on selections
- File upload requirements
- Address standardization
- Payment integration
- Activity-specific annexes
- Data validation requirements
